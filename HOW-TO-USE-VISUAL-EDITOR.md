# How to Use CloudCannon Visual Editor 🎨

## 🔍 **Switching to Visual Editor**

You're currently in the **Data Editor** (form view). To access visual editing:

### Step 1: Look for Editor Tabs
At the top of the page, you should see tabs like:
- **Visual** ← Click this one!
- **Content** 
- **Data** (this is where you are now)

### Step 2: Click "Visual"
This will switch you to the visual editing mode where you can:
- See your actual webpage
- Click on text to edit it inline
- See visual indicators when hovering

## 🎯 **Visual Editor Features**

### What You'll See:
- **Yellow outlines** when hovering over editable text
- **Blue section borders** around editable regions
- **"Click to edit"** indicators
- **Real-time preview** of your changes

### What You Can Edit Visually:
- ✏️ **Headlines and text** - Click any text to edit
- ✏️ **Hero section** - Title, subtitle, CTA button
- ✏️ **Main content** - Rich text editor
- ✏️ **Images** - Click to replace
- ✏️ **Benefits, FAQ, Process Steps** - Edit via sidebar

## 📝 **Simplified Data Editor**

I've also simplified your Data Editor (form view) so it's less overwhelming:

### Now Shows Only:
- **Page Basics**: Title, subtitle, category
- **Hero Section**: Image, CTA text
- **Content Arrays**: Benefits, process steps, FAQ
- **SEO**: Description, keywords

### Hidden Technical Fields:
- Layout settings
- Navigation settings
- Build configurations
- Template versioning
- Other technical metadata

## 🎨 **Visual Editing Tips**

1. **Start with Visual Editor** for content changes
2. **Use Data Editor** for structured data (benefits, FAQ)
3. **Hover to see** what's editable
4. **Click text directly** to edit it
5. **Use sidebar** for arrays and images
