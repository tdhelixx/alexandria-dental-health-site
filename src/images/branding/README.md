# Branding Assets

This folder contains logos, brand elements, and identity assets.

## Files to Add:
- `header-logo.webp` - Main header logo
- `footer-logo.webp` - Footer logo (if different)  
- `favicon.ico` - Site favicon
- `logo-dark.webp` - Dark version of logo
- `logo-light.webp` - Light version of logo
