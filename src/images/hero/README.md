# Hero Images

This folder contains hero/banner images used across the site.

## Naming Convention:
- `service-[service-name]-hero.webp` - Service page heroes
- `page-[page-name]-hero.webp` - General page heroes  
- `home-hero.webp` - Homepage hero image

## Recommended Dimensions:
- **Desktop**: 1200x600px minimum
- **Mobile**: Ensure images work at 800x400px  
- **Format**: WebP preferred for performance
