# Gallery Images

This folder contains before/after photos and smile gallery images.

## Subfolders:
- `before-after/` - Treatment before/after photos
- `smile-gallery/` - General smile photos  
- `cases/` - Specific case studies

## Naming Convention:
- `case-[number]-before.webp` / `case-[number]-after.webp`
- `smile-[number].webp` for general gallery photos
