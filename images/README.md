# Images Directory

This directory contains ALL images for the Alexandria Dental Health website.

## Simple Structure - All images in one flat directory

Copy ALL files from `wp-content/uploads/` subdirectories to this single `images/` folder.

## Copy Instructions:

**From WordPress structure:**
```
wp-content/uploads/2025/01/Dentist-Alexandria-VA-Alexandria-Dental-Health-Smile-Studio-Header-Logo.webp
wp-content/uploads/2025/02/Dentist-Alexandria-VA-Case-Study-33-Before.webp
wp-content/uploads/2025/02/Dentist-Alexandria-VA-Case-Study-33-After.webp
... (all other image files)
```

**To simple structure:**
```
images/Dentist-Alexandria-VA-Alexandria-Dental-Health-Smile-Studio-Header-Logo.webp
images/Dentist-Alexandria-VA-Case-Study-33-Before.webp
images/Dentist-Alexandria-VA-Case-Study-33-After.webp
... (all files in one directory)
```

## Benefits:
✅ **Simple** - One directory, no complex organization  
✅ **Fast** - Copy everything at once  
✅ **No path issues** - All images accessible at `/images/filename.webp`  
✅ **Easy maintenance** - No folder structure to manage  

## Usage in templates:
```
/images/Dentist-Alexandria-VA-Alexandria-Dental-Health-Smile-Studio-Header-Logo.webp
/images/any-other-image-file.webp
```
